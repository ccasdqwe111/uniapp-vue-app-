# uniapp+vue志愿者活动报名服务系统app小程序

源码地址：ym7k.com/18968/

基于 uniapp+vue 开发的志愿者活动报名服务小程序，一套代码可同步适配微信小程序、APP 等多端，面向志愿者、活动管理员、平台审核人员三类角色设计，打通活动发布、在线报名、签到打卡、时长统计、证书发放全流程，为志愿服务管理提供一体化线上解决方案，下面从功能维度介绍整套系统的搭建思路与业务能力。

面向普通志愿者的前端功能是小程序的核心使用入口。用户进入小程序后可以完成账号注册与实名认证，提交身份信息等待后台审核，审核通过后解锁全部服务权限。首页集中展示各类志愿服务活动，支持按活动类型、服务地点、活动时间、招募状态筛选检索，活动详情页清晰展示服务内容、招募人数、起止时间、服务地点、注意事项、负责人联系方式。志愿者选定合适活动后可以直接在线提交报名，提交后实时查看报名状态，区分待审核、报名成功、名额已满、审核驳回等状态，驳回时附带管理员备注说明。

报名成功的志愿者，可在个人中心统一管理自己的所有活动订单。系统内置签到签退功能，支持定位签到或者二维码签到两种模式，管理员在后台生成签到码，志愿者到达现场扫码完成签到，服务结束后签退，系统自动记录本次服务的起止时间。同时提供消息提醒能力，活动即将开始、报名审核结果、签到通知、活动变更、取消通知都会推送提醒，避免志愿者错过活动。个人中心还会自动汇总累计服务时长、参与过的历史活动，生成个人志愿服务档案。

管理员后台承担活动统筹管理工作。管理员可以自主发布志愿服务项目，填写活动基础信息，设置招募人数、报名起止时间、是否需要审核、签到方式、服务时长换算规则，发布之后活动自动在小程序前端展示。报名列表可以查看所有提交报名的志愿者信息，批量或者单独审核报名申请，支持同意、驳回操作。签到管理模块实时查看到场人员名单，查看未签到、已签到、已签退人员，支持手动补录签到记录，应对定位异常、扫码失败等突发情况。

数据统计与证书模块是系统的增值功能。系统自动统计各项活动的报名人数、实际到场人数、总服务时长，生成可视化统计数据，支持按时间段导出志愿服务台账，方便上报存档。满足条件的志愿者可以在线申领电子志愿服务证书，后台可以自定义证书模板，证书自动填充姓名、活动名称、服务时长、服务日期，生成电子证书供志愿者保存下载。

系统配套完善的权限管理和基础配置功能，可以划分多级管理员账号，不同账号分配不同权限，部分账号仅负责审核报名，部分账号可以发布活动、查看全部数据。后台还支持设置服务分类、用户协议、轮播公告，发布平台通知公告。同时自带风控限制，可设置单个活动报名上限、防止重复报名，志愿者可自主取消报名，超出限定时间取消会留下记录，规范报名秩序。

整体搭建以业务流程为核心，先搭建用户实名与账号体系，再开发活动发布与报名链路，接着配置签到打卡、消息通知，最后完善时长统计和证书功能。uniapp 多端特性让这套系统不用重复开发，小程序和 APP 共用一套业务逻辑，兼顾志愿者便捷使用和管理人员高效统筹，实现志愿服务从线下手工登记转向数字化管理。
